# r4ss

The CRAN release of `r4ss` is a compatibility package. It replaces the
out-of-date CRAN implementation and directs users to the actively maintained
package on GitHub:

<https://github.com/r4ss/r4ss>

Install the current package with `pak`:

```r
install.packages("pak")
pak::pkg_install("r4ss/r4ss")
```

Alternatively, use `remotes`:

```r
install.packages("remotes")
remotes::install_github("r4ss/r4ss")
```

Documentation is available at <https://r4ss.github.io/r4ss/> and issues can
be reported at <https://github.com/r4ss/r4ss/issues>.
